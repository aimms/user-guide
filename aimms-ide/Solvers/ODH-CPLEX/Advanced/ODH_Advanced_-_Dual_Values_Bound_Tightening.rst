Dual Values Bound Tightening
============================



:Type:	Selection
:Range:	The settings listed below
:Default:	Yes



This option specifies whether reduced costs from CPLEX are used to tighten global bounds. Possible values are:



    *	No
    *	Yes




**Note**

*	This option was added in ODH-CPLEX 8.2.
