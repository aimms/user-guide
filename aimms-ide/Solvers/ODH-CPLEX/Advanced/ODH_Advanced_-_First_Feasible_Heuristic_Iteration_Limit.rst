First Feasible Heuristic Iteration Limit
========================================



:Type:	Integer
:Range:	{0 .. 2100000000}
:Default:	0



This option sets a limit on the number of relaxed re-solves in the first feasible heuristic. Possible values are:




.. list-table::

   * - 0
     - No relaxed re-solves (default)
   * - >0
     - Limit on the number of relaxed re-solves




**Note**

*	This option was added in ODH-CPLEX 8.2.
