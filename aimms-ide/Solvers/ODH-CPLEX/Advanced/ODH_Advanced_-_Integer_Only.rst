Integer Only
============



:Type:	Selection
:Range:	The settings listed below
:Default:	Automatic



This option specifies which variables are included in the keys used for grouping variables into sub-models. Possible values are:



    *	Automatic
    *	All variables
    *	Only non-continuous variables




**Note**

*	This option was added in ODH-CPLEX 8.2.
