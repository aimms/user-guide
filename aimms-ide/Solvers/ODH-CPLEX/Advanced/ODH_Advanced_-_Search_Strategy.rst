Search Strategy
===============



:Type:	Selection
:Range:	The settings listed below
:Default:	Automatic



This option specifies the search strategy used by CPLEX for the main solve and for the sub-model solves. Possible values are:



    *	Automatic
    *	Traditional branch and cut
    *	Dynamic search




**Note**

*	This option was added in ODH-CPLEX 8.2.
