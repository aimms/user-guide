Sub Node Limit
==============



:Type:	Integer
:Range:	{-1 .. 2100000000}
:Default:	-1



This option sets the node limit for sub-model searches. Possible values are:




.. list-table::

   * - -1
     - Automatically determined (default)
   * - >0
     - Use this value as node limit




**Note**

*	This option was added in ODH-CPLEX 8.2.
