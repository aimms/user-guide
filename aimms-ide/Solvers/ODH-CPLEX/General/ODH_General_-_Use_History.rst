Use History
===========



:Type:	Selection
:Range:	The settings listed below
:Default:	Automatic



This option controls the use of past sub-model selections in the current sub-model selection. Possible values are:



    *	Automatic
    *	Never use historical information
    *	Always use historical information




**Note**

*	This option was added in ODH-CPLEX 8.2.
