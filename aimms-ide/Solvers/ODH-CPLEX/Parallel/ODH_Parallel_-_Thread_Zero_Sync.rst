Thread Zero Sync
================



:Type:	Selection
:Range:	The settings listed below
:Default:	Sync with multiple CPLEX threads



This option specifies which CPLEX threads are used for synchronization. Possible values are:



    *	Sync with multiple CPLEX threads
    *	Only sync with CPLEX thread 0




**Note**

*	This option was added in ODH-CPLEX 8.2.
